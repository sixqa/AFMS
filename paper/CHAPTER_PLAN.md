## Thesis Statement

> Scaling aquaculture phenotyping is bottlenecked by per-species software redevelopment, because anatomical definitions, measurement rules, quality-control logic, and output schemas are embedded in application code. AFMS replaces this with a minimal species protocol that decouples "what to measure" (defined by the researcher) from "how to detect it" (performed by interchangeable perception modules and a shared runtime). The same protocol simultaneously guides model generation, ONNX deployment, runtime inference, depth-aware geometric measurement, quality control, and structured phenotype export. We demonstrate this across five morphologically diverse aquaculture taxa spanning three taxonomic orders, with zero runtime code modification per species, achieving operational-level batch phenotyping at 98.8% success rate.

## INSIGHT Collection

### [INSIGHT: thesis_statement]
Protocol-driven architecture decouples "what to measure" (breeder intent) from "how to detect it" (model implementation), transforming species adaptation from software engineering into protocol definition. This is not a convenience improvement—it is an architectural paradigm shift.

### [INSIGHT: introduction_repositioning]
Introduction 从"领域很重要 + 技术可行"的综述式铺陈，转变为"育种家需要一个不需要写代码的表型测量框架"的故事驱动型引言。Gap 定位从 "software redevelopment per species" 精确为 "breeders can't write code, existing tools don't solve this"。

### [INSIGHT: methods_architecture_evidence]
Methods 关键转变：从概念化的"协议 schema 表"转变为代码级证据驱动。validate() 的 6 层语义校验、crayfish 用语义关键点名（tou1/zhonbu/wei1）、generate.py 的模板填充机制——这些代码事实直接证明协议控制的是语义层而非参数层。

### [INSIGHT: results_narrative_reversal]
Results 从"先报告模型指标"转变为"先展示系统是什么、能做什么"。关键变化：(1) 架构图放到 Results 开头；(2) 批量处理从"压力测试"重新定位为"育种家实操验证"；(3) 模型指标降级为感知模块验证。

### [INSIGHT: discussion_reorientation]
Discussion 从"重复 thesis"转变为"Results 意味着什么"。核心论述：从模型中心到基础设施的范式转变——CV 社区的贡献评价标准（新模型=SOTA）与水产育种的实际需求（可用系统）之间存在错配，AFMS 弥合了这个错配。

### [INSIGHT: competitive_landscape]
无直接对标软件。对比方式从"软件 vs 软件"转变为"工作流 vs 工作流"：传统开发（改 Python ~200 行/物种）vs 协议工作流（写 YAML ~20 行/物种）。审稿人无法反驳"没有对标"，因为他看到的是工作流的客观差异。

### [INSIGHT: depth_measurement_positioning]
深度测量从"独立创新"降级为"协议通用性的证明"。同时补充标签标定模式，形成三模态测量（2D像素/标签标定/结构光3D），均由同一协议驱动。这证明协议不仅跨物种通用，还跨测量模态通用。
